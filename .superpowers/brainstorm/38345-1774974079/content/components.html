Componentes UI reutilizáveis
MountainDivider

Props: fromColor, toColor, flip?, variant?: "A"|"B"|"C". SVGs com Bézier preservados do HTML de referência. Usado 4× na landing.

BridgeDivider

Props: fromColor, toColor, showFigure?, showAntTrail?. Cabos catenários + silhueta humana do HTML preservados.

AntTrail

Props: direction?: "horizontal"|"ascending", color?, opacity?. Pontos em perspectiva (raio e opacidade decrescentes) extraídos do HTML.

Button

Variantes: primary, secondary, white, outline-white. Renderiza <a> ou <button> conforme prop href.

Comportamentos automáticos (via config/site.ts)
Inscrições fechadas → abertas: Mudar event.registrationsOpen para true e preencher registrationsUrl. Automaticamente, Hero e CTA trocam "Avise-me" por "Inscrever agora" apontando para a URL.
Parceiros "em breve" → confirmados: Adicionar parceiros.realizadores[] em site.ts. O componente Parceiros.tsx detecta o array e renderiza os chips automaticamente — sem if espalhado.
Logo texto → gráfica: Colocar arquivo em public/logo.svg e mudar theme.logo.textMode para false. Nav e Footer atualizam automaticamente.
Página /empresas — formulário
Form com campos: Nome da empresa, Nome do responsável, Email, Mensagem (opcional). Sem action de backend por enquanto — marcado com {'/* TODO: plugar backend aqui */'}. Visual idêntico ao resto do site (CSS vars + mesma tipografia). Fácil de trocar para mailto:, Netlify Forms ou qualquer API depois.
Animações e responsividade

@keyframes fadeUp com delays escalonados no Hero preservados em CSS puro (sem Framer Motion). Breakpoint em 960px: nav collapsa, hero vira 1 coluna, steps vira 2×2, footer empilha.

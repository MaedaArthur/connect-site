Sistema de configuração — fonte única de verdade
config/site.ts

Todos os textos, dados do evento, flags (registrationsOpen, registrationsUrl), URLs e listas de conteúdo. A equipe edita só este arquivo para mudar textos.

config/theme.ts

Todas as cores, fontes e tokens visuais. O app/layout.tsx importa e injeta como CSS variables no <head> (Abordagem C).

Fluxo: theme.ts → layout.tsx injeta <style>:root{'{'}--azul:#003399...{'}'} → componentes usam var(--azul) via CSS Modules / globals.css
